How to annotate

Question 1 — Same meaning?

Answer Yes if the English-letter text represents the same Kannada words/meaning. Small spelling differences are okay if the meaning is still clear.

Example — Yes
ನಾನು ಇವತ್ತು ಮನೆಗೆ ಹೋಗಬೇಕು.
nanu ivattu manege hogbeku
Example — No
ನಾನು ಇವತ್ತು ಮನೆಗೆ ಹೋಗಬೇಕು.
nanu nale manege hogbeku
nale changes “today” to “tomorrow.”

Question 2 — Would you type it this way?

Imagine you are messaging someone in Kannada but using English letters. Answer Yes if this spelling is a plausible way you might type it.

This is not a colloquialness question. A Kannada sentence may be formal or colloquial. Here you are judging only how Kannada is represented with English letters.

Plausible texting
ನಾನು ಮನೆಗೆ ಹೋಗಬೇಕು.
nanu manege hogbeku
Meaning may be correct, but typing may feel unnatural
ನಾನು ಮನೆಗೆ ಹೋಗಬೇಕು.
nānu manege hōgabēku
This is a formal transliteration style. You can mark meaning Yes and typing No if you would not normally type Kannada this way.

When to skip

Skip if you do not understand the Kannada sentence well enough to judge it. Skipping is better than guessing.

Important

Do not search online, use transliteration tools, use an AI assistant, or ask another person. We want your own judgment.
